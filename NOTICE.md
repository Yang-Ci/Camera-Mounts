## V2 data collection camera mount

`data-collection-camera-mounts/data-collection-camera-mount-v2.stp` was supplied locally by the repository maintainer as `数据采集摄像头支架.stp`. It is the V2 aluminum extrusion support assembly with a 3D-printed camera bracket. Only the filename was translated; the original STEP bytes are preserved. This file is a separate maintainer contribution and is not attributed to the V1 upstream repository. No separate license was specified with this contribution.

`images/data-collection-camera-mount-v2.png` is rendered directly from that assembly geometry.
