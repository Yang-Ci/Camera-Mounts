# Camera Mounts

Unified camera mount and data collection asset collection for reBot and related robotics experiments.

## Contents

- `b601-camera-mounts/`
  - B601-RS / B601-DM camera mounts
- `data-collection-camera-mounts/`
  - Data collection camera mount variants
- `data-collection-environment/`
  - Data collection environment assets

## Sources

- B601 camera mounts: [Seeed-Projects/reBot-DevArm](https://github.com/Seeed-Projects/reBot-DevArm)
- Data collection camera mounts: [xiehuangbao888/Camera-Mount](https://github.com/xiehuangbao888/Camera-Mount)
- Data collection environment: [yuyoujiang/rebot-arm-dli-isaacsim](https://github.com/yuyoujiang/rebot-arm-dli-isaacsim)

## Notes

- Original filenames are preserved.
- Formats include STEP (`*.step`, `*.stp`) and USDZ (`*.usdz`).
- Licensing information is in `NOTICE.md` and `licenses/`.
